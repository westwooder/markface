# markface

Windows 桌面程序：选一个视频，自动把画面里的人脸打上马赛克。

不需要目标机器装 Python —— 打包后是一个自带运行环境的文件夹，双击 `markface.exe` 即可。

## 下载

[**下载 markface-v1.0-windows-x64.zip**](https://github.com/westwooder/markface/releases/latest)（约 250MB）

解压后双击 `markface.exe`。不需要装 Python，不需要装任何依赖。

完整使用说明见 [USAGE.zh-CN.md](USAGE.zh-CN.md)。

## 直接使用

1. 解压 zip，双击 `markface.exe`
2. 选视频（也可以直接拖进窗口）
3. 预览确认范围 → 开始打码

## 界面说明

**常用**标签页
- 加速方式：自动 / GPU（DirectML，支持 NVIDIA、AMD、Intel 显卡）/ CPU
- 识别强度：快速 / 均衡 / 严格
- 马赛克范围：横向、纵向、上下位置、粗细、遮挡厚度、压暗、柔化、羽化、形状

纵向范围默认 0.78，比检测框矮 —— 额头和下巴轮廓留在马赛克外面，只遮五官。

**觉得码不够厚就调「遮挡厚度」**（默认 1.0×，可到 3.0×）。它按倍数放大色块，
同时在取色块均值前先压平细节 —— 不压平的话，睫毛、蒙眼布边缘这类高对比线条
会把所在色块的均值拽偏，五官轮廓仍会隐约透过色块。

「压平细节」默认开启。「压暗程度」默认 0.10，让码块看起来是有意为之的实色块，
而不是一团模糊。柔化默认 0.12，调到 0 是纯像素块。

**检测与跟踪**标签页
- 人脸阈值：越低召回越高，误检也越多
- YuNet 二次检测：另一套架构的检测器，补 YOLO 的漏
- 姿态推断头部：脸被完全遮住（蒙眼+堵嘴、背对镜头、戴头套）时，靠身体关键点定位头部
- 遮挡补偿：检测框因遮挡缩成一条时自动补全成完整脸部比例
- 丢失后续遮 / 断档插补 / 平滑窗口：控制跟踪的连续性

**输出**标签页
- 保留声音：音轨直接复制，不重新编码
- 画质：默认「跟随原视频」—— 读取源文件的编码器（H.264/HEVC）、码率和像素格式，
  按同样规格输出，画面观感与原片一致。也可以手动指定 CRF 或选近无损。
- CPU 线程数

检测框只画在预览里，**输出文件永远不含彩色框**。

## 抗遮挡怎么做的

蒙眼、堵嘴这类情况下，人脸检测器有两种失败方式，程序分别处理：

1. **完全检不到** → 姿态模型检出身体，用鼻/眼/耳/肩关键点反推头部框。
   五官关键点一个都看不见时，退化到"肩宽 × 比例"估算头部位置。
2. **检到但框缩小** → 遮挡时框常常只剩可见的那一条（实测眼嘴都遮住时，
   框高从 82px 缩到 29px，只剩额头）。两重补偿：按正常脸部长宽比
   （约 1.32）把扁框补高；同一条跟踪链记住历史最大框，不允许缩到 72% 以下。

三层检测结果取并集，重叠的去重 —— 任一检测器报了某个区域，这个区域就会被遮。

## 不漏帧怎么做的

两趟处理：

- 第一趟逐帧检测 + IoU/质心跟踪。检测丢失时轨迹按速度继续外推（默认续 30 帧）。
- 第二趟渲染前，把整段视频的检测结果串成轨迹链，中间的空洞用两侧插值回填
  （默认 12 帧以内），首尾各外扩 6 帧，再做 5 帧滑窗平滑去抖。

单趟流式处理只能向前猜，两趟能"回头看"，中间漏的帧可以用后面的检测结果补。

## 从源码运行

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe tools\fetch_models.py
.venv\Scripts\python.exe main.py
```

中国大陆网络下模型下载失败，加镜像参数：

```powershell
.venv\Scripts\python.exe tools\fetch_models.py --mirror hf-mirror.com
```

## 打包

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物在 `dist\markface\`。整个文件夹拷走即可，目标机器无需 Python。

## 模型

| 用途 | 模型 | 大小 |
|---|---|---|
| 人脸（快速） | YOLOv11s-face | 38MB |
| 人脸（均衡/严格） | YOLOv11m-face | 80MB |
| 人脸二次确认 | YuNet | 0.2MB |
| 姿态推断头部 | YOLO26n-pose | 12MB |

下载地址写在 `models/manifest.json`，`tools/fetch_models.py` 按表下载。

## 日志

`%APPDATA%\markface\markface.log`，设置存在同目录的 `settings.json`。
